    Who's playing?

    Give each player a nickname and a time limit. When time runs out, a loud chime rings, the game saves, and everyone goes back to the arcade home screen to pass the device to the next player.

    Turn up the volume so everyone can hear the chime. The timer keeps counting while you pick a game on the home screen.

    Grown-up lock

    Set a 4-digit PIN so only a grown-up can pause, add time, skip a turn, end the timer or change the players.

    How it works

    1. Pick players and times, then press Start turns. The first player goes first.
    2. A timer bubble with the player's name shows on every page and in every game. Drag it if it's in the way.
    3. With one minute left, a soft chime gives a heads-up to find a good place to stop.
    4. When time's up, a loud chime rings, the game saves, and it's back to the home screen.
    5. The home screen says who's next. Games stay locked until the next player taps to start their turn.

    Everything stays on this device. Turns are shared across all the games here, but not with other phones or computers.
