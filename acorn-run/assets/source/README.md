# Source art

`asset-sheet.png` is the original hand-drawn asset sheet. Every sprite in
`../atlas.webp` was cut from it: the squirrel poses, skunks, acorns, terrain
tiles, scenery props and the mountain panorama.

Kept here as the master copy. The packed atlas and its rect table in
`../../src/atlas.js` were generated from this sheet together and must stay in
sync with each other — if you repack, regenerate both in the same pass.

Not every piece on the sheet is in the game yet. Unused so far: the tree stump,
the cliff and ramp terrain pieces, and the small floating island.
